# FreeVPNConfigsForRussia
Бесплатный VPN конфигурации для РФ
Где какие находятся?
В файле ChackedWhitelists находятся проверенные вручную ключи для LTE
В файле CheckedBlacklist находятся проверенные вручную ключи для Wi-Fi
В файлах UncheckedBlacklists и UncheckedWhitelists находятся непроверенные ключи
В файле Subscriptions находятся ключи подписок из проверенных Telegram ботов
