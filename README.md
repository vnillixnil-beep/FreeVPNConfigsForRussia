# FreeVPNConfigsForRussia

**Бесплатные VPN-конфигурации для РФ**

## 📂 Структура репозитория

### ✅ Проверенные вручную

| Файл | Описание |
|------|----------|
| **CheckedWhitelists** | Проверенные вручную ключи для **LTE** |
| **CheckedBlacklist** | Проверенные вручную ключи для **Wi-Fi** |

### ⚠️ Непроверенные

| Файл | Описание |
|------|----------|
| **UncheckedBlacklists** | Непроверенные ключи (Blacklist) |
| **UncheckedWhitelists** | Непроверенные ключи (Whitelist) |

### 📡 Подписки

| Файл | Описание |
|------|----------|
| **Subscriptions** | Ключи подписок из проверенных Telegram-ботов |

---

> 💡 **Совет:** Начинайте с файлов `CheckedWhitelists` и `CheckedBlacklist` — там находятся вручную проверенные ключи, которые с наибольшей вероятностью будут работать.
